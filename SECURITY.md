# Security policy

## Supported versions

Security fixes are made on the latest released version and the `main` branch.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting form under **Security → Advisories
→ Report a vulnerability**. Please do not include a vulnerability, private
session data, captured commands, or filesystem paths in a public issue.

Include the tmux-recover and tmux versions, operating system, reproduction
steps, and the smallest sanitized snapshot or log excerpt that demonstrates the
problem. You should receive an acknowledgement within seven days.

tmux-recover snapshots can contain session names, pane titles, working
directories, and process arguments. Treat snapshots and restore reports as
sensitive local data even when reporting a non-security bug.
